# 原岩攀岩比賽系統：上線步驟

照順序做，每一步做完再做下一步。全部都是在網頁上點一點，不需要安裝任何程式。
大約需要 30～40 分鐘。

> 網站後台的按鈕名稱偶爾會改版，如果找不到一模一樣的字，找意思相近的就可以。

---

## 第 0 步：先處理 GitHub 上的選手資料（很重要）

你的 GitHub 倉庫 `yammincode/compmodel` 目前是 **公開的（Public）**，而之前上傳的
`data/firebase-export.json`（選手姓名＋路線照片）任何人都看得到。

新版程式已經把 `data/` 排除，以後不會再上傳；但**舊的那份還留在 GitHub 的歷史紀錄裡**。最快的處理方式：

1. 打開 https://github.com/yammincode/compmodel
2. 點上方 **Settings** → 拉到最下面 **Danger Zone** → **Change visibility** → 改成 **Private**

改成 Private 之後只有你看得到，Netlify 一樣可以讀取。
（如果你想讓倉庫維持公開，就需要把歷史紀錄裡的檔案徹底清掉，這個可以請 Claude 幫你做，但會改寫歷史，要先跟 Claude 確認。）

---

## 第 1 步：建立 Supabase 專案

1. 打開 https://supabase.com → 右上角 **Sign in** → 選 **Continue with GitHub**（用你的 GitHub 帳號登入最方便）
2. 點 **New project**
3. 填寫：
   - **Name**：`origin-climb`
   - **Database Password**：按 **Generate a password**，然後**把密碼存到安全的地方**（之後很少用到，但遺失很麻煩）
   - **Region**：選 **Northeast Asia (Tokyo)**（離台灣最近，比較快）
   - 方案選 **Free** 就夠用
4. 按 **Create new project**，等 1～2 分鐘建立完成

---

## 第 2 步：開啟「匿名登入」並放寬限制

選手不用註冊就能報名，靠的是「匿名登入」，預設是關的。

1. 左邊選單 **Authentication** → **Sign In / Providers**
2. 找到 **Allow anonymous sign-ins**，打開 → 按 **Save changes**
3. 左邊選單 **Authentication** → **Rate Limits**
4. 找到匿名登入的限制（**Number of anonymous sign-ins per hour**，預設 30）→ 改成 **300** → **Save**

> 為什麼要改？比賽時大家都連館內 Wi-Fi，對 Supabase 來說是「同一個網路位址」。
> 預設一小時只讓 30 個人匿名登入，第 31 個選手會進不來。

---

## 第 3 步：建立資料庫（執行 schema.sql）

1. 左邊選單 **SQL Editor** → 點 **+**（New query）
2. 打開 GitHub 上的 [`supabase/schema.sql`](../supabase/schema.sql)，按右上角的「複製」圖示，**整份**複製
3. 貼到 SQL Editor 裡 → 按右下角 **Run**
4. 看到 **Success. No rows returned** 就成功了

> 這份檔案可以重複執行，不會刪掉資料。以後資料庫有更新，也是一樣整份貼上再 Run。

---

## 第 4 步：建立你的系統管理員帳號

1. 左邊選單 **Authentication** → **Users** → 右上角 **Add user** → **Create new user**
2. 填你的 Email 和一組密碼，**勾選 Auto Confirm User** → **Create user**
3. 回到 **SQL Editor**，開一個新的 query，貼上這一行（把 email 換成你剛剛填的）：

   ```sql
   insert into app_admins(user_id) select id from auth.users where email = '你的email@example.com' on conflict do nothing;
   ```

4. 按 **Run**，看到 **Success** 就好了

---

## 第 5 步：記下兩個設定值

1. 左邊選單最下面的齒輪 **Project Settings** → **API Keys**（或上方的 **Connect** 按鈕）
2. 記下兩個東西：
   - **Project URL**：長得像 `https://abcdefgh.supabase.co`（在 **Project Settings → Data API** 或 Connect 裡）
   - **anon public key**（舊名稱）或 **Publishable key**（新名稱，`sb_publishable_` 開頭），兩個都可以用

> ⚠️ 頁面上還有一把 **service_role** 或 **secret** key，**那把絕對不要給任何人、不要貼到網站或 GitHub**，它可以跳過所有權限。
> anon / publishable key 是設計給網站公開使用的，安全由資料庫的權限規則把關（已經測試過）。

---

## 第 6 步：把網站放上 Netlify

> 先確認新版程式已經合併到 GitHub 的 `main` 分支（Claude 會開一個 Pull Request 給你，按 **Merge** 就好）。

1. 打開 https://app.netlify.com → **Sign up / Log in** → 選 **GitHub** 登入
2. 點 **Add new project**（或 Add new site）→ **Import an existing project** → 選 **GitHub**
3. 第一次會要求授權 Netlify 讀取 GitHub，選 **Only select repositories** → 選 `compmodel` → 授權
4. 選擇 `compmodel` 倉庫，分支選 **main**
5. 建置設定**不用改**（程式裡的 `netlify.toml` 已經寫好了：發布 `web` 資料夾）
6. 找到 **Environment variables**（或 **Add environment variables**），新增兩個：

   | Key | Value |
   |---|---|
   | `SUPABASE_URL` | 第 5 步的 Project URL |
   | `SUPABASE_ANON_KEY` | 第 5 步的 anon / publishable key |

7. 按 **Deploy**，等 1 分鐘左右，畫面會出現網址，例如 `https://xxxx-xxxx-123.netlify.app`
8. （可選）**Site configuration** → **Change site name**，改成好記的名字，例如 `origin-climb` → 網址變成 `https://origin-climb.netlify.app`

之後只要 GitHub 的 `main` 有更新，Netlify 會**自動重新部署**，不用再做任何事。

> 如果打開網站看到「尚未設定 Supabase」：代表第 6 步的環境變數沒設好。設好之後到 **Deploys** → **Trigger deploy** → **Deploy site** 重新部署一次。

---

## 第 7 步：告訴 Supabase 你的網址

1. 回到 Supabase → **Authentication** → **URL Configuration**
2. **Site URL** 填 Netlify 的網址（例如 `https://origin-climb.netlify.app`）→ **Save**

---

## 第 8 步：搬移舊的「原岩模擬賽」資料

1. 用電腦打開你的網站
2. 拉到最下面 → **管理員登入** → 輸入第 4 步的 Email 和密碼
3. 下面會多出 **匯入資料** → 選擇電腦裡的 `data/firebase-export.json`
4. 等它跑完（10 張照片會一張一張上傳），出現「匯入完成」就好了

> 舊比賽的主辦會變成你（系統管理員）。進比賽頁就看得到新的管理碼，可以給原本的主辦或裁判。
> 舊資料裡用 Firebase 帳號自行報名的選手，因為帳號沒辦法搬過來，會變成「主辦新增的選手」，成績都保留。

---

## 第 9 步：用兩支手機實測

找另一個人（或用兩支手機）照著做，每一項都打勾：

**手機 A（當主辦）**
- [ ] 打開網站 → **建立新比賽** → 跳出管理碼，記下來
- [ ] 按 **複製比賽連結**，用 LINE 傳給手機 B
- [ ] 按 **開始** 計時

**手機 B（當選手）**
- [ ] 點 LINE 裡的連結，直接進到比賽
- [ ] 計時器和手機 A 差不到 1 秒，而且在倒數
- [ ] 看不到「開始／暫停」按鈕
- [ ] 填名字 → **報名** → 點「路線 1」→ 按 **Zone**、**Top** → 分數 24.9
- [ ] 手機 A 的排行馬上出現這位選手和 24.9 分

**手機 A**
- [ ] 按最下面 **選手自行記分：開放中** 把它關掉 → 手機 B 的記分按鈕變灰
- [ ] 在「路線 1」按 **上傳路線照片** → 拍一張岩壁 → 圈幾個點 → **儲存**
- [ ] 手機 B 切到「路線 1」看得到照片和圈圈，點照片可以放大

**手機 B（模擬裁判／換手機）**
- [ ] 按 **輸入管理碼** → 輸入手機 A 的管理碼 → 出現計時按鈕
- [ ] 按 **暫停** → 手機 A 也跟著暫停

**最後**
- [ ] 手機 A 按 **刪除這場比賽**，兩支手機都回到入口頁

全部打勾就可以正式使用了！🎉

---

## 之後要注意的事

- **免費方案的 Supabase 一週沒人用會自動暫停**。比賽前一兩天打開 Supabase 後台看一下，如果顯示 Paused，按 **Restore project** 等幾分鐘就恢復（資料不會不見）。常常辦比賽的話可以考慮升級 Pro 方案（每月約 25 美元，不會暫停、每天自動備份）。
- **定期備份**：用管理員登入後按 **匯出備份**，會下載一個 JSON 檔（含照片），存到雲端硬碟。
- 免費方案的照片空間是 1GB，一張路線照片約 100～150KB，可以放好幾千張。
